# Seguridad

Proyecto personal sin autenticación integrada ni SLA de seguridad. No exponer listas reales sin control de acceso.

Para un fallo sensible, usa **Security → Report a vulnerability** si está habilitado. Si no, contacta al propietario por un canal privado acordado. No publiques contraseñas, dumps ni datos personales en issues.

Incluye commit, reproducción sin datos reales e impacto. Revoca secretos expuestos: borrarlos de un commit no elimina su historial.
