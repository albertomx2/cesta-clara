# Contribuir

Abre un issue antes de cambios amplios. Describe cambio y comprobaciones en cada pull request.

- No incluyas listas reales, contraseñas, dumps ni capturas privadas.
- Respeta condiciones y límites de las fuentes; no eludas controles de acceso.
- Distingue precio por envase y precio unitario, y unidades incompatibles.
- Ejecuta las comprobaciones del README y documenta fuentes y zonas.
- Usa SECURITY.md para fallos sensibles. El código propio todavía no declara licencia open source.
